## 6. Gates the survey saw that a learned selection meets, collected

- A new runtime package: `package.json` and `package-lock.json` both change, `npm ci` must pass in CI and the deploy; the patch-note check gives the commit a reader-facing prefix.
- A model file and a runtime's binary file in `public` (or emitted under `dist`): both go into the service worker's shell list by default with no size or type test (`vite.config.ts` lines 435 to 465), so both are downloaded in every install that lacks the same bytes and an unfetchable one fails the install; the host's limit for one file is unchecked by the build.
- A new worker: a `.ts` under `src` loaded by the existing `new Worker(new URL(...), { type: "module" })` shape; it needs an opening comment for the module map, contracts on its exported functions, and no `debug-` prefix in its chunk name.
- Any edit to a `src` file: the line count in `docs/ARCHITECTURE.md` changes, so `architecture-check` needs `--write` and the file staged.
- The preview key: only files in the preview-version list move `PREVIEW_PIPELINE`; a selection that stays on the test page touches none of them.
- CI text size: `debug.html` and `src/style.css` carry no fixed pixel font size.
